## Default Permission

Accessibility query permissions.
Enables the get_font_scale, is_screen_reader_enabled and is_touch_explore_enabled commands.

#### This default permission set includes the following:

- `allow-get-font-scale`
- `allow-is-screen-reader-enabled`
- `allow-is-touch-explore-enabled`
