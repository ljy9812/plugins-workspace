## Default Permission

Continuation permissions.
Enables the is_continuation_restore, get_continuation_data and set_continuation_data commands.

#### This default permission set includes the following:

- `allow-is-continuation-restore`
- `allow-get-continuation-data`
- `allow-set-continuation-data`
